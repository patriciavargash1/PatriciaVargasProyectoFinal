# Proyecto de Arquitectura de Software - Módulo III

## Objetivo
Gestionar el ciclo de vida de un proyecto de arquitectura de software mediante el uso de ramas, seguimiento de tareas (Issues) y documentación técnica detallada en este repositorio remoto.

## Contexto del Proyecto
Este repositorio simula el entorno de trabajo de un arquitecto de software. El enfoque principal es la organización de la documentación técnica, la creación de "contratos" de API y el diseño del sistema, asegurando un registro profesional de cada avance.

## Planificación (Issues)
Para este proyecto, se han definido las siguientes tareas principales:
1. **Diseño de endpoints REST**: Documentación de los contratos de la API REST.
2. **Definición de esquema GraphQL**: Optimización de consultas para evitar el over-fetching.
3. **Diagrama de arquitectura**: Representación visual del diseño del sistema.

## Flujo de Trabajo
- **Ramas (Branches)**: Se utiliza una rama independiente para cada tarea (ej. `feat/rest-api`), evitando trabajar directamente en la rama `main`.
- **Integración**: Los cambios se integran mediante Pull Requests (PR) vinculados a sus respectivos Issues.
- **Documentación**: Todo el diseño técnico se encuentra en archivos con formato Markdown (.md).
